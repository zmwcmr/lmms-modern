# Legacy theme (frozen)

This directory is a frozen copy of `data/themes/default` taken on
2026-11-28, before the icon redesign. It is kept for visual comparison and
rollback. See `doc/ui-spec.md` §3.2 for the frozen A icon language.

- Do not add new icons or features here.
- New work goes to `data/themes/default`.
- The snapshot intentionally preserves the old artwork, including known
  issues such as empty disabled scrollbar arrows.
