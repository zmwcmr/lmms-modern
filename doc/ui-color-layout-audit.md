# 界面颜色与文字布局检查

检查基线：当前工作区，2026-11-28。此记录是源码静态检查和用户截图的结果；并非全部窗口、主题、语言和缩放比例的视觉验收。

## 统一标准

- 可点击 URL 使用主题提供的绿色 `QPalette::Link`，保留下划线；已访问链接默认同色。键盘焦点必须可见。普通文字中出现的不可点击 URL 使用正文色。
- 普通文字、按钮、菜单和标签页使用主题正文色；标签页以背景、边框和字重表示选中，不用链接绿表示普通或选中状态。
- 禁用、选中、警告、错误、录音、波形和音符颜色各自保留语义；用户在项目笔记中设置的颜色和第三方插件自己的界面不由 LMMS 强制改色。
- 主题应分别提供链接色、正文色及状态色。普通文字和链接以实际相邻背景为准，目标对比度至少 4.5:1；不能只按窗口背景取值。链接不可只用颜色区分。
- 自适应布局优先按字体度量和内容计算；允许有限空间内省略的名称应提供完整名称的可访问途径。面板不能为适应固定尺寸而悄悄把常规文字缩小。大字号、长翻译和窄窗口都要检查。

候选链接色：`#8cfab6` 与默认背景 `#262b30`、About 面板近似背景 `#4d565e`、经典主题背景 `#5b6571` 的对比度分别约为 11.20、5.86、4.64。该数值只是候选，实际颜色还需按真实绘制背景及悬停、焦点、禁用状态验收。默认主题正文 `#d1d8e4` 对经典主题背景约为 4.13，不能把某一背景上的合格结果推广到所有界面。

## 颜色现状

- About 的 URL 和 LV2 插件详情现使用主题 `QPalette::Link`，默认与经典主题设置为 `#8cfab6`；调色板变化时更新已生成的富文本。仍需实际桌面检查所有背景和链接状态。
- 默认主题 `LmmsPalette` 的 `windowText` 仍为绿色 `#1de276`，但默认和经典主题的 Qt 标签页已明确指定正文色；需要在真实窗口核实所有状态。
- `ProjectNotes` 保存和展示用户编辑的 HTML；它不是静态主题链接清单，不能批量覆盖用户指定的文字或链接颜色。插件提供的外部原生界面和第三方内容也不属于本次源码静态检查的覆盖范围。

## 文字布局

已从用户截图确认 About 版本信息右侧截断；版本标签现已启用换行，仍需检查长版本号、翻译、窗口可调整性和 100%–200% 字体缩放。

## 验收范围

优先覆盖默认与经典主题、100%/125%/150%/200% 字体、英文和较长翻译、窄窗口，以及 About、重命名、文件浏览器、插件选择器和上述插件。检查文字实际绘制边界、焦点、滚动和可点击性；不能仅凭编译、固定尺寸搜索或离屏测试宣布全部界面通过。第三方插件和操作系统原生窗口单独记录。
